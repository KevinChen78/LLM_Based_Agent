# 依赖准备指南

由于当前网络环境无法直接访问 GitHub，CMake 的 `FetchContent` 无法自动下载依赖。以下是几种解决方案：

## 方案 A：配置代理（推荐）

如果你已有代理软件（如 Clash、V2Ray、Shadowsocks），请配置 git 使用代理：

```bash
# HTTP 代理
 git config --global http.proxy http://127.0.0.1:7890
 git config --global https.proxy http://127.0.0.1:7890

# SOCKS5 代理
 git config --global http.proxy socks5://127.0.0.1:7890
 git config --global https.proxy socks5://127.0.0.1:7890
```

然后重新运行：

```powershell
cd D:\Working\LLM_Based_Agent
.\scripts\build_windows.ps1
```

## 方案 B：手动下载依赖

如果无法配置代理，请手动下载以下依赖并放到 `third_party/` 目录：

### 1. nlohmann/json (v3.11.3)

下载单头文件版本：
- URL: `https://github.com/nlohmann/json/releases/download/v3.11.3/json.hpp`
- 放到：`third_party/nlohmann/json.hpp`

### 2. cpp-httplib (v0.15.3)

下载单头文件版本：
- URL: `https://github.com/yhirose/cpp-httplib/raw/v0.15.3/httplib.h`
- 放到：`third_party/httplib/httplib.h`

### 3. spdlog (v1.14.1)

下载源码并解压：
- URL: `https://github.com/gabime/spdlog/archive/refs/tags/v1.14.1.zip`
- 解压到：`third_party/spdlog/`

### 4. googletest (v1.14.0)

下载源码并解压：
- URL: `https://github.com/google/googletest/archive/refs/tags/v1.14.0.zip`
- 解压到：`third_party/googletest/`

目录结构示例：

```text
third_party/
├── nlohmann/
│   └── json.hpp
├── httplib/
│   └── httplib.h
├── spdlog/
│   └── include/spdlog/...
└── googletest/
    └── googletest/...
```

然后修改 `cmake/FetchDependencies.cmake` 使用本地路径，或修改 `CMakeLists.txt` 直接 include。

## 方案 C：使用镜像

如果你知道可用的 GitHub 镜像，可以修改 `cmake/FetchDependencies.cmake` 中的 URL：

```cmake
make_github_url("https://mirror.example.com/https://github.com/nlohmann/json.git" JSON_URL)
```

## 方案 D：使用 vcpkg

如果你有 vcpkg 并且可以访问镜像，可以安装依赖后通过 vcpkg toolchain 构建：

```powershell
vcpkg install nlohmann-json spdlog cpp-httplib gtest
cmake -B build -S . -DCMAKE_TOOLCHAIN_FILE=C:\vcpkg\scripts\buildsystems\vcpkg.cmake
```
