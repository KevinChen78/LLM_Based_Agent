# Phase 0 工具链安装脚本（Windows）

## 当前状态

- Visual Studio Installer 已存在：
  `C:\Program Files (x86)\Microsoft Visual Studio\Installer\setup.exe`
- Visual Studio 2022 实例尚未安装。

## 命令行安装（管理员）

以管理员身份打开 **PowerShell**，执行：

```powershell
& "C:\Program Files (x86)\Microsoft Visual Studio\Installer\setup.exe" `
  install `
  --productId Microsoft.VisualStudio.Product.Community `
  --channelId VisualStudio.17.Release `
  --installPath "C:\Program Files\Microsoft Visual Studio\2022\Community" `
  --add Microsoft.VisualStudio.Workload.NativeDesktop `
  --add Microsoft.VisualStudio.Component.CMake `
  --add Microsoft.VisualStudio.Component.Windows11SDK.22621 `
  --add Microsoft.VisualStudio.Component.VC.CMake.Project `
  --includeRecommended `
  --passive `
  --norestart
```

### 参数说明

| 参数 | 含义 |
|---|---|
| `Microsoft.VisualStudio.Workload.NativeDesktop` | **使用 C++ 的桌面开发** 工作负载 |
| `Microsoft.VisualStudio.Component.CMake` | CMake 工具 |
| `Microsoft.VisualStudio.Component.Windows11SDK.22621` | Windows 11 SDK |
| `Microsoft.VisualStudio.Component.VC.CMake.Project` | 用于 CMake 的 C++ 工具 |
| `--includeRecommended` | 包含推荐组件 |
| `--passive` | 显示安装进度，但不等待用户交互 |
| `--norestart` | 安装完成后不自动重启 |

## 安装后验证

```powershell
# 检查 cl.exe
& "C:\Program Files\Microsoft Visual Studio\2022\Community\VC\Auxiliary\Build\vcvarsall.bat" x64
cl

# 检查 cmake
cmake --version

# 使用 vswhere 验证
& "C:\Program Files (x86)\Microsoft Visual Studio\Installer\vswhere.exe" -latest -property displayName
```

## 如果命令行安装失败

1. 打开 **Visual Studio Installer**（开始菜单搜索）。
2. 点击 **“安装”** → **“Visual Studio Community 2022”**。
3. 勾选 **“使用 C++ 的桌面开发”**。
4. 在右侧 **“安装详细信息”** 中确认勾选：
   - MSVC v143 - VS 2022 C++ x64/x86 生成工具
   - Windows 11 SDK
   - C++ CMake tools for Windows
5. 点击安装。
