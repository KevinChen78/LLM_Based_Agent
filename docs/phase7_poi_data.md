## 数据来源与合规

- 数据源:**高德开放平台 Web 服务 API**(`/v3/place/text` 与 `/v3/place/around`,
  `extensions=all` 取真实评分)。这是合规 API 调用,不是爬虫,不使用任何
  反爬绕过手段。
- 用途:**个人学习/演示**,数据集不分发(`data/` 已 gitignore,POI 原始数据与
  生成结果均不入库 git)。
- 真实字段:商户名、地址、坐标、区县、评分;团购属性(价格/原价/销量/人数)
  按 `md5(poi_id)` 确定性合成——**deal 是合成的,商户是真实的**,面试讲述时
  必须主动说明这一边界。
